# M3aya Santé brand assets

User-supplied `brand-board.png` is preserved unchanged, including transparency. The three SVG files embed the same PNG in separate viewports: light logo, dark logo and favicon. They exclude the board's variant captions without regenerating or recoloring the artwork. These are raster-backed SVG files, not vector tracings.

Use the light variant on white, dark on navy, and favicon for compact branding. Preserve proportions and alternative text. The software license does not grant independent trademark rights in this artwork.
